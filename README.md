# Граф зависимостей Python — вариант 14, этап 1

Параметры командной строки: package, repository, test-repo, max-depth.
Значения проверяются и выводятся как ключ-значение.

```bash
sh run.sh --package requests --max-depth 2
make test
python3 -m pip install -r requirements-dev.txt
make check
```

Сборка не требуется. Основная программа использует стандартную библиотеку.
Проверка конфигурации разделена на функции с одной задачей.
Radon проверяет сложность каждого блока, включая вложенные функции.
Строки ограничены 80 символами, функции — 40 строками, сложность — 10.

## Этап 2

urllib получает `<repository>/<package>/json`; json разбирает ответ.
Прямые зависимости извлекаются из info.requires_dist, точная версия —
из info.version. Markers фильтруются для текущей ОС и Python.
Готовые менеджеры и библиотеки зависимостей не используются.

```bash
sh run.sh --package requests --stage 2
```

Без запрошенных extras их зависимости не включаются. Неподдерживаемые
markers и динамические зависимости дают ошибку. Локальный тестовый граф
и рекурсивный обход добавляются следующим этапом.
